# VLUR 의미와 서비스 이용 흐름

VLUR는 Verify · Learn · User · Reliability의 약자로, 사용자 행동을 학습하여 신뢰성을 검증하는 AI 보안 서비스입니다. 멀티모달 LLM의 발전으로 무력화되고 있는 기존 이미지·문자 기반 CAPTCHA의 보안 한계와 티켓팅 서비스의 매크로 대량 선점 문제를 해결하고, 빠른 인증 속도와 높은 보안성을 동시에 요구하는 구조적 딜레마를 극복하기 위해 ASCII 아트와 행동 기반 인증을 결합한 차세대 사용자 인증 기술입니다.

VLUR CAPTCHA는 완전관리형 서비스입니다. CAPTCHA 문제(아스키아트, 정답, 경유 지점 등)는 개발자가 직접 만드는 게 아니라 VLUR 서버가 자동으로 생성합니다. 개발자(고객사)는 API Key로 "문제 생성 API"를 호출해 문제를 받아 자기 서비스 화면에 표시하고, 최종 사용자가 드래그를 마치면 그 결과를 "검증 API"로 보내 통과/차단 여부만 받으면 됩니다. 즉 개발자가 할 일은 API 연동뿐이고, CAPTCHA 문제 생성이나 정답 관리는 전부 VLUR가 대신합니다.

어디에 쓸 수 있냐는 질문에는: 웹사이트 전반(회원가입, 로그인, 결제 등)에 적용할 수 있지만, 특히 콘서트·공연 티켓팅 사이트에 특화되어 있다고 답합니다. 매크로를 이용한 대량 좌석 선점(어뷰징)을 막기 위해 만들어졌고, 빠른 인증 속도(평균 통과 시간 0.59초)와 높은 보안성을 동시에 요구하는 티켓팅 환경에 맞춰 설계됐습니다. 네이티브 모바일 앱 지원 여부는 확인된 바 없으므로 지어내지 않습니다.

모바일 터치 환경도 지원합니다. 모바일 브라우저에서 손가락으로 터치해 드래그하는 동작도 마우스 드래그와 동일하게 궤적 분석 대상이 됩니다. "모바일/터치 환경에서 지원하지 않는다"고 답하면 틀린 답입니다.

# CAPTCHA 유형과 아스키 지각

현재 두 가지 유형이 있습니다. 핵심 동작은 두 유형 모두 동일한 "드래그 앤 드롭"입니다 — 4지선다 보기 중 정답을 손가락/마우스로 잡고 경유 지점을 거쳐 목표 위치까지 끌어다 놓으면, 그 이동 궤적(경로·속도·가속도 등)을 분석해 사람인지 봇인지 판별합니다. 정답을 맞히는 것과 별개로 이 드래그 동작 자체가 핵심 판별 기준입니다.

두 유형의 차이는 "무엇을 드래그하게 만드는가"뿐입니다. 유형 1은 "바나나를 골라주세요"처럼 아스키 아트로 표현된 한글 지시문을 보여주고 그 지시에 맞는 보기를 드래그하게 하며, 유형 2는 아스키 아트로 표현된 이미지를 보여주고 같은 대상을 보기 중에서 찾아 드래그하게 합니다. 유형 1 실패(봇 의심도가 높을 때) 시 유형 2로 자동 전환하여 봇의 연속 시도를 차단합니다.

아스키 아트란 아스키 코드 0x20~0x7E 범위의 문자·기호만으로 명암과 형태를 표현한 그림입니다. 사람 눈에는 문자 패턴 속 형상이 자연스럽게 인식되지만, 이미지 인식 모델은 픽셀이 아니라 문자 배열로 이를 처리해야 하기 때문에 일반 CNN·OCR 기반 자동 인식이 어려워집니다. VLUR CAPTCHA는 이미 두 유형 모두에서 문제를 이 아스키아트로 표현하고 있습니다. "아스키 지각"이란 사람은 문자로 이루어진 아스키아트도 눈으로 쉽게 형태를 알아보는 반면, VLM(이미지-언어 인식 AI)은 일반 사진·이미지 인식에 최적화되어 있어 문자 패턴으로 그려진 이미지를 상대적으로 잘 인식하지 못하는, 사람과 AI 사이의 인지 능력 차이를 뜻합니다. VLUR CAPTCHA는 이 차이를 활용해 사람에게는 쉽고 이미지 인식 기반 봇에게는 어려운 문제를 만듭니다. 다만 최종 봇 판별의 핵심은 아스키아트 인식 자체가 아니라 드래그 궤적(움직임 패턴) 분석에 있고, 아스키아트·정밀 드래그 배치는 스크립트 봇의 난이도를 높이는 보조 장치입니다.

"정밀 드래그 배치"란 정답 보기를 아무 데나 놓는 게 아니라, 경유 지점을 순서대로 거쳐 정확한 목표 위치에 픽셀 단위로 정밀하게 가져다 놓아야 통과되는 방식을 말합니다. 사람은 눈으로 보고 자연스럽게 위치를 맞추지만, 스크립트·매크로 봇은 보통 정해진 좌표로 순간 이동하거나 일직선으로 움직이는 식이라 이런 경유 지점 통과와 정밀한 드롭 위치를 재현하기 어렵습니다. 즉 "정밀 드래그 배치로 스크립트 난이도가 상승한다"는 말은, 목표 지점을 정확히 맞춰야 하는 요구 조건 자체가 봇에게는 추가 장벽이 된다는 뜻입니다.

CAPTCHA를 언제 보여주는 게 좋냐는 질문에는 다음을 권장안으로 안내합니다. 회원가입 가입 완료 직전, 결제 플로우에서는 결제하기 버튼을 누르기 직전, 티켓팅 사이트처럼 매크로 대량 선점이 우려되는 경우에는 예매하기 버튼을 누른 직후입니다.

지표는 두 세트로 구분됩니다. 메인페이지 맨 위에 표시된 지표는 평균 통과 시간 0.59초, 봇 차단율 88.3%, 검증 응답 약 30ms입니다. 이 수치는 데이터 수집용 사이트를 배포해 실제 트래픽으로 측정한 기준입니다 — 실시간으로 매번 다시 계산되는 값이 아니라, 그 배포·수집 시점 기준의 측정값입니다. 이와 별도로 모델 자체 검증 지표는 분류 정확도 97.5%, 오탐률 0.3% 이하, 검증 처리량 초당 25~40건입니다(이쪽은 검증 데이터셋 기반 측정). "검증 응답 속도"나 "봇 차단율"을 물으면 메인페이지 지표(88.3%, 30ms)로 답하고, "정확도"나 "오탐률"을 물으면 모델 지표(97.5%, 0.3%)로 답합니다. 두 세트를 섞지 않습니다.

CAPTCHA 때문에 이탈이 늘지 않냐는 질문에는, 평균 통과 시간 0.59초·검증 응답 약 30ms로 매우 빠르다는 사실과 정상 사용자는 대부분 즉시 통과한다는 점을 근거로 답합니다.

검증 방법론은 실제 사람 사용자의 드래그 궤적 데이터와, 매크로·스크립트로 생성한 봇 드래그 데이터를 함께 모아 검증 데이터셋을 구성하고, CNN+BiLSTM 모델이 이 둘을 얼마나 정확히 구분해내는지 측정해 97.5% 정확도·0.3% 오탐률을 얻는 방식입니다. 데이터셋의 정확한 규모, 사람 대 봇 비율, 수집 기간 같은 세부 수치는 공개하지 않습니다.

AI 에이전트로도 실제 테스트를 진행했습니다. 사이트 URL과 "대신 예매해줘" 같은 프롬프트를 주고 에이전트가 스스로 CAPTCHA를 풀게 하는 방식입니다. 에이전트는 먼저 유형 1 CAPTCHA를 마주치는데, 아스키 아트로 표현된 지시문을 텍스트로 인식하는 데만 상당한 시간이 걸리고, 설령 인식에 성공해 정답을 맞혀도 드래그 궤적 자체가 봇으로 판별되면 유형 2로 자동 전환됩니다. 유형 2에서도 아스키 아트 이미지를 판독하는 데 다시 상당한 시간이 걸리고, 마찬가지로 드래그 궤적으로 봇 판별되어 접근이 차단됩니다. 즉 아스키 지각(이미지·텍스트 인식 자체의 어려움)과 드래그 궤적 분석(행동 기반 판별)이라는 두 겹의 방어가 AI 에이전트에게도 동일하게 작동함을 확인했습니다.

데모 체험: 회원가입이나 로그인 없이도 메인페이지 맨 위쪽의 [지금 체험하기] 버튼을 누르면 실제 CAPTCHA를 바로 풀어볼 수 있는 데모 창이 뜹니다.

# 요금제, 결제, 변경

요금제는 상단 메뉴에 있는 별도 링크나 별도 페이지가 아니라, 메인페이지를 아래로 스크롤하면 나오는 [요금제] 섹션입니다. 메인페이지 맨 위쪽의 [요금제 보기] 버튼을 누르면 페이지 이동 없이 그 섹션으로 스크롤됩니다.

요금제는 세 가지입니다. Basic(무료, 월 10만 호출), Pro(₩89,000/월, 월 50만 호출), Enterprise(문의, 무제한). Basic은 [무료로 시작하기], Pro는 [결제하고 시작하기], Enterprise는 [도입 문의하기] 버튼을 눌러 바로 진행합니다.

요금제별 상세 기능은 다음과 같습니다. 세 요금제 모두 CAPTCHA 유형 1·2를 지원합니다(이건 공통이라 차별점이 아닙니다).
- Basic: 기본 드래그 궤적 검증, API Key 1개, 대시보드 분석·우선 기술 지원·SLA 보장은 제공하지 않습니다.
- Pro: 고급 드래그 궤적 + 이상 행동 감지, API Key 최대 5개, 대시보드 분석(30일 보관), 이메일 우선 지원. SLA 99.9% 보장은 제공하지 않습니다(Enterprise 전용).
- Enterprise: Pro의 모든 기능 포함 + SLA 99.9% 보장, API Key 무제한, 전담 매니저 지원, 온프레미스 배포 가능, 커스텀 모델 학습 지원.
"Basic에 대시보드 지원이 있냐"처럼 물으면 없다고 정확히 답하세요 — Basic에만 없는 기능을 있다고 답하면 틀린 답입니다.

홈페이지 [요금제] 섹션에서 원하는 요금제의 버튼을 누르면 바로 시작할 수 있습니다. Basic은 무료라 [무료로 시작하기] 버튼을 누르면 결제 없이 바로 가입되고, Pro는 [결제하고 시작하기] 버튼을 누르면 결제 페이지로 이동합니다. 결제는 카카오페이 단건결제 또는 토스페이먼츠 결제위젯 v2를 지원하며, 월 단위 구독이라 언제든 해지 가능합니다. 연 단위 구독은 아직 지원하지 않습니다.

요금제는 언제든 변경할 수 있습니다. 마이페이지 > 결제 내역 탭의 [요금제 변경] 버튼, 또는 메인페이지 [요금제] 섹션에서 원하는 플랜 버튼을 눌러 바로 변경할 수 있습니다. 상위 요금제로 업그레이드하면 결제 즉시 적용되고, 하위 요금제로 다운그레이드하면 다음 결제 주기부터 적용되도록 예약됩니다.

# 도메인 등록과 로컬(localhost) 테스트

VLUR CAPTCHA는 다른 유명 캡차 서비스들처럼, API Key를 발급할 때 "이 캡차는 어느 웹사이트 주소에서만 쓸 수 있다"는 걸 미리 등록해두는 방식을 씁니다. 그래서 등록해둔 주소가 아닌 다른 곳에서 요청이 오면 캡차가 동작하지 않습니다. 이 등록된 주소는 마이페이지 > API Key 관리에서 언제든 바꿀 수 있습니다. 그러니 개발 중에 내 컴퓨터(localhost)에서 테스트하고 싶다면 등록 주소를 "localhost"로 바꿔두면 되고, 나중에 실제 서비스를 오픈할 때 실제 도메인 주소로 다시 바꿔주면 됩니다.

# API Key와 토큰

API Key 발급은 홈페이지 [요금제] 섹션에서 원하는 요금제 버튼(무료로 시작하기/결제하고 시작하기)을 눌러 가입을 완료한 뒤, 마이페이지 > API Key 관리 탭으로 이동해 "사이트 도메인"(예: example.com, 개발 환경은 프로토콜·경로 없이 localhost 입력 가능)을 입력하고 [키 발급] 버튼을 누르면 Site Key와 Secret Key가 발급됩니다. 가입만으로 자동 발급되는 것이 아니라 도메인 입력과 발급 버튼 클릭이 필요합니다. Secret Key 원문은 발급 시 한 번만 표시됩니다.

API Key가 노출·유출됐을 때는 마이페이지 > API Key 관리에서 [키 재발급] 버튼을 누르면 기존 키가 즉시 무효화되고 새 키가 발급됩니다.

검증 성공 시 발급되는 one-time token의 기본 유효 시간은 180초(3분)입니다. 재사용 불가하며 만료 시 CAPTCHA를 다시 풀어야 합니다.

일회성 토큰과 rate limit으로 대량 시도를 막는 방식: 토큰이 한 번 검증에 쓰이면 즉시 소모되어 재사용이 불가능하므로, 같은 토큰을 반복 제출하는 방식의 매크로 공격이 통하지 않습니다. 여기에 더해 짧은 시간에 몰리는 대량 요청은 별도로 속도 제한(rate limit)을 걸어 걸러내고, 문제의 선택지 순서·배치도 매번 무작위로 섞어 좌표만 외워서 반복 클릭하는 매크로 패턴 학습을 막습니다. 정확한 제한 수치는 보안상 비공개입니다.

# 가이드 페이지 (연동 방법 3단계)

가이드는 별도의 상단 메뉴나 푸터 링크가 아니라, 메인 페이지와 마이페이지의 API Key 관리에서 확인할 수 있습니다. API Key 발급부터 토큰 검증까지 3단계로 안내합니다.

1단계 — API Key 발급: 회원가입/로그인 → 요금제 선택(Basic은 즉시 발급) → 마이페이지 > API Key 탭에서 키 확인. 키 형식은 `vlur_live_sk_...`로 시작합니다. API Key는 반드시 서버 환경변수(.env)에만 저장하고, 클라이언트(브라우저) 코드에 넣거나 깃허브 같은 공개 저장소에 커밋하면 안 됩니다.

2단계 — CAPTCHA 요청: 서버에서 `GET https://api.vlur.dev/v1/captcha`를 `Authorization: Bearer $VLUR_API_KEY` 헤더와 함께 호출하면, `captcha_id`, `ascii_image`(아스키아트), `ui_type`, `options`(보기 목록)가 담긴 응답을 받습니다. 이 `ui_type` 값(choice/drag)은 API 응답 필드일 뿐, 앞서 설명한 "유형1/유형2"(문제를 한글 지시문으로 보여주는지 이미지로 보여주는지의 구분)와는 다른 개념입니다 — 서로 대응시켜 설명하지 마세요. 모든 CAPTCHA는 결국 경유 지점을 지나 정답 보기를 드래그해서 제출합니다. CAPTCHA 요청은 사용자 행동이 필요한 시점 직전(예: 결제 버튼 클릭 직후)에 하는 것을 권장합니다.

3단계 — 검증/Token: 사용자 응답을 `POST https://api.vlur.dev/v1/verify`로 `captcha_id`와 `answer`를 담아 보내면, 성공 시 `{ success: true, token, expires_in: 180 }`을 받습니다. 이 일회성 token을 이후 요청(예: 주문 생성)의 `X-Captcha-Token` 헤더에 담아 보내면 되고, 서버는 최종 처리 전에 token을 다시 검증해야 합니다. token은 1회 사용 후 즉시 만료되며 발급 후 180초(3분) 이내에만 유효합니다.

빠른 연동(위젯 한 줄): 프론트엔드에 아래 스크립트 태그만 추가하면 위젯이 붙습니다.
```html
<div class="vlur-captcha" data-sitekey="YOUR_SITE_KEY"></div>
<script src="https://js.vlur.dev/v1/api.js" async defer></script>
```

# 개발자 연동 (SDK, 위젯 커스터마이징)

SDK는 React, Vue, FastAPI, Node.js, Django 등을 지원합니다. 가입 완료 후 가이드 페이지에서 확인할 수 있고, 마이페이지에서도 동일하게 확인할 수 있습니다. SDK란 VLUR CAPTCHA를 개발자가 자기 서비스에 쉽게 연동할 수 있도록 제공하는 코드 패키지·도구 모음을 뜻합니다.

통합 코드 예시를 요청받으면 거절하지 않고, 위 가이드 페이지의 실제 엔드포인트(문제 요청 `GET /v1/captcha`, 검증 `POST /v1/verify`)와 응답 형식을 근거로 코드 예시를 보여줍니다.

CAPTCHA 위젯의 크기 변경은 지원하지 않지만, 색상(브랜드 HEX 색상)은 변경할 수 있습니다. 마이페이지 > API Key 관리에서 해당 API Key로 표시되는 CAPTCHA의 강조 색상을 지정할 수 있습니다.

다크 모드는 두 가지를 구분해야 합니다. VLUR CAPTCHA 홈페이지(웹사이트) 자체는 우측 상단 토글 버튼으로 다크 모드를 지원합니다. 반면 API Key를 발급받아 실제 서비스에 삽입하는 CAPTCHA 위젯(사용자가 문제를 푸는 화면) 자체는 다크 모드를 지원하지 않습니다.

# 계정과 마이페이지

마이페이지는 우측 상단 [로그인] 후 API Key 관리, 사용량 조회, 결제 내역, 계정 탈퇴 등을 확인할 수 있는 곳입니다. 마이페이지 > 사용량 조회 탭에서 사용량 데이터를 CSV로 내려받을 수 있습니다.

로그인·회원가입은 화면 우측 상단에 [로그인] 버튼과 [회원가입] 버튼이 나란히 있습니다. 이메일로 가입하려면 [회원가입] 버튼을 눌러 바로 회원가입 페이지로 이동해 진행합니다. 카카오·네이버·구글 소셜 로그인은 [로그인] 페이지의 소셜 로그인 버튼 하나로 회원가입과 로그인이 함께 처리됩니다 — 처음 누르면 자동으로 계정이 만들어지고, 이후에는 같은 버튼으로 로그인됩니다. 소셜 계정 이용자는 별도로 회원가입 페이지를 거칠 필요가 없습니다.

비밀번호 변경은 마이페이지 > 내 정보 탭 > "비밀번호 변경" 버튼을 클릭해 현재 비밀번호 확인 후 새 비밀번호(8~16자, 영문 대소문자·숫자·특수문자 포함)를 입력하면 됩니다.

이메일 인증은 회원가입 시 이메일로 발송되는 인증코드(6자리)를 입력해 인증하며, 인증코드는 발급 후 일정 시간(수 분) 내에만 유효합니다.

계정 탈퇴는 마이페이지 > 계정 탈퇴 탭에서 진행할 수 있으며, 탈퇴 시 API Key와 데이터가 삭제됩니다.

# 공지사항과 하단(푸터) 링크

공지사항은 홈페이지 상단 메뉴의 [공지사항] 링크를 클릭하면 공지사항 게시판으로 이동해 확인할 수 있습니다.

메인페이지 맨 아래쪽(하단)에는 [이용약관], [개인정보처리방침], [GitHub], [문의하기] 링크가 있습니다. 이용약관과 개인정보처리방침은 누르면 그 자리에서 내용을 보여주는 창(모달)이 뜨고, GitHub는 새 탭으로 저장소(https://github.com/kakao-NoBot/AI-Captcha)가 열리며, 문의하기는 누르면 문의 작성 창이 뜹니다. 별도로 이동하는 "이용약관 페이지"나 "일반 문의 페이지" 같은 건 없고, 전부 같은 화면에서 버튼 클릭으로 바로 열립니다.
